PAWAN RAO TRADER — Free Website Starter

## Is package mein kya hai?
- Premium black & gold responsive trading website
- Risk calculator
- Profit/loss calculator
- Trade journal (browser ke local storage mein)
- Login / Signup demo modal
- WhatsApp aur YouTube buttons
- Hindi-friendly labels and risk disclosure

## Mobile par test kaise karein
1. ZIP extract karein.
2. `index.html` ko browser mein open karein.
3. Calculators aur journal use karke dekhein.

## Free mein online publish karna
Aap GitHub Pages ya Netlify jaise static hosting par upload kar sakte hain. `index.html` ko publish karne se website live ho jayegi. Free hosting providers ke plans/terms badal sakte hain.

## Apna WhatsApp number add karna
`index.html` mein `https://wa.me/` dhoondhein aur apne international format number se replace karein. India ke number ke liye `91` + 10 digit number, bina `+`, spaces ya dash ke. Example format: `https://wa.me/91XXXXXXXXXX`.

## Important limitations
- Login/Signup abhi sirf demo UI hai. Ye users ko securely register/authenticate nahi karta.
- Trade journal isi browser/device par save hota hai; dusre device par sync nahi hota.
- Real admin panel, secure user accounts, cloud database, password reset, analytics aur multi-device sync ke liye backend/auth/database setup chahiye.
- Website investment advice ya profit guarantee nahi deti. Trading mein loss ka risk hai.
